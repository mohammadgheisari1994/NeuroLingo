# Lightweight CI subset — no heavy ML/audio packages needed for unit tests.
# flet IS included (despite being the UI framework) because tests/unit/test_main.py
# imports main.py, which imports flet at module level — without it, test collection
# fails on CI even though it passes locally (flet is already installed there via the
# full requirements.txt). flet has prebuilt wheels and no GPU/ML dependencies, so it
# doesn't violate the "lightweight" goal this file exists for.
# flet-audio / flet-audio-recorder are the same story: main.py imports them at
# module level for the Shadowing exercise's playback/recording controls — both
# are thin Flutter-plugin wrappers with prebuilt wheels, not heavy ML deps.
# soundfile/scipy are needed by neurolingo/audio's own tests (waveform
# comparison runs on plain synthetic WAV fixtures, no microphone/TTS engine
# involved) — pyttsx3 and sounddevice are NOT here since those need real
# hardware/OS engines unavailable on CI runners; that code path is exercised
# via is_available()-guarded tests instead.
